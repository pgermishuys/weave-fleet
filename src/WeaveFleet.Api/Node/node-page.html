Fleet node

This computer runs sessions for another Fleet

A node has no web app of its own, so there's nothing to sign in to here. You work with it from another Fleet.

  1. Open Fleet on the computer you work from, or the desktop app.
  2. Go to Settings → Machines → Add a machine.
  3. Paste this address and the node's access token:
    this page's address

The token was printed when the node started. The node keeps it next to its data, in fleet.machine.json.
