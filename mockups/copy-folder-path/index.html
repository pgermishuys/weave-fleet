Copy folder path

"Quite often I want to be able to copy the directory that I am currently in. We show the directory in the top header; maybe if I hover over it, it could show a copy icon where I can just copy the directory."

Today the only way is right-click on the session in the list, then Copy path. The header shows the path as plain text that cuts off at the end, so on a narrow window you lose the folder's own name. Three ways to fix it below, on the same invented session. Every option copies the full path, however much of it is showing.

Which folder, and the awkward cases

Worktree sessions

"The directory I'm in" is the session's working folder, the worktree, because that's where the agent's changes are and where you'd cd to run them. The header already shows that one. B and C also offer the source repo, which Fleet knows for every worktree session.

Long paths

A and B cut the start of the path, not the end, so …/fleet-session-7f3a9c21 stays readable. C shows only the folder's name and gives the whole path in its popover. All of them copy the full path.

Windows

Copied exactly as Fleet has it, backslashes and spaces included: C:\Users\Sam Rivera\code\orbit-api. B's Copy as cd command quotes it the way that machine's shell needs.

Another machine

The path belongs to that machine, so copying still works (you'd paste it into an ssh session). B's and C's Open in are off there, with the reason, as in the session list's menu today.

Keyboard and screen readers

The copy control is a real button in the tab order, with a visible focus ring. Its name is "Copy folder path", its tooltip shows the full path, and "Folder path copied" is read out once. Nothing depends on hover alone.

No hover

On a touch screen A's icon is always shown at reduced strength. Where the header has no room for a path (the phone app, a very narrow window), every option adds a Copy folder path row to the ⋯ menu (below).

Phone

Fleet's phone app shows only the folder's name in the header, and there's no hover. The same change goes in for every option: a Copy folder path row in the ⋯ menu, confirmed with the phone's usual toast. A desktop browser window that narrow keeps the desktop header, which has no room for the path at all, so its ⋯ menu gets the same row.

Recommendation: A

It's the ask as you described it, one click, and the smallest change. Two things come with it:

  • The path cuts from the start, so the folder's own name stays visible on a narrow window.
  • A Copy folder path row in the ⋯ menu, both the phone app's and the desktop header's, for when there's no room to show the path.

If you also want the source repo, a cd line or Open in from the header, B's menu can go on A's path later as a right-click, without changing what a click does.
