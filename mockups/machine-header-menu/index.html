Start a session on another machine

A report asks how to start a session on a machine that isn't live: right-clicking the machine's name does nothing, and there's no way to switch to it. Two ways exist today, but neither is where they looked: the Machine chip under the new-session box, and Settings → Machines → Work here. A machine with no sessions can't be reached from the sidebar at all.

Today

  • Right-click on a machine's name does nothing; a click only folds it.
  • build-box has no sessions, so nothing in the sidebar leads to it.
  • The Machine chip sits in the strip under the new-session box, next to Folder. It works, but you have to know it's there.
  • Try: right-click build-box.

A · Right-click menu recommended

  • Right-click a machine's name (or press the menu key on it) for New session on build-box and Work here, the same words as Settings → Machines.
  • New session opens the new-session page with the Machine chip already set. Nothing switches until you send, as today.
  • Work here makes it live, like clicking one of its sessions. The order stays put; only the Live tag moves.
  • The live machine's menu has just New session.
  • An empty machine's “No sessions” line gets a New session link.
  • Try: right-click build-box, or the link under it.

B · Menu and a + on hover

  • Everything in A, plus a + on each machine's heading when you hover it.
  • Easier to find for people who never right-click, and it works on touch.
  • Project headings don't have a +, so machines would be the odd ones. It also covers the “4s ago” note while you hover.
  • Try: hover studio or build-box.
