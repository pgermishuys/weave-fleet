3 · An agent that goes too deep (what it reads)

Fleet refuses POST /api/sessions from an agent whose session is already 3 agent-starts below a session the user started (a session the user moved out counts as the user's). Subagents inside a harness are the harness's business; they don't count.

$ curl -s -X POST "$FLEET_URL/api/sessions" -H "X-Fleet-Harness-Session: $FLEET_HARNESS_SESSION_ID" -d '{…}' HTTP 409 {"error":"This session is 3 levels down from a session the user started; Fleet doesn't let agents start sessions deeper than that. Ask the user, or do the work here."}
