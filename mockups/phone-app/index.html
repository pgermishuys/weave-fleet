How it works underneath

The same four pieces for every option

01

Reach the machine

The phone talks to the Fleet you already run, over tailscale serve HTTPS. A relay for phones without Tailscale is a separate step later.

02

Pair once

The QR code holds a one-time secret. Redeeming it gives the phone its own key, which you can remove. The shared machine token stays for desktops.

03

Install

A manifest and a service worker make Fleet installable. The service worker shows notifications and opens the right session when you tap one.

04

Notify

When an agent asks (permission.asked), asks a question, finishes or fails, Fleet sends a Web Push. Skipped while Fleet is open on a screen.
